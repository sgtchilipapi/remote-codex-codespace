## Agent skills

### Issue tracker

Issues are tracked as local Markdown files in this repository. Read `docs/agents/issue-tracker.md` before creating, triaging, claiming, resolving, or wayfinding issues.

### Triage labels

Triage uses the five default canonical labels. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses the single-context layout. See `docs/agents/domain.md`.

### Safe build pushes

Before a requested deployment-build-gated branch push, read `skills/safe-build-push/SKILL.md` and follow its two-phase build and push transaction.
